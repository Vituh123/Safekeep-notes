# 🔒 SafeKeep Notes

Um cofre digital seguro para anotações sensíveis. Desenvolvido com foco em segurança, utilizando criptografia de dados e boas práticas de proteção de senhas.

## 🚀 Funcionalidades

- **Criptografia Avançada:** O conteúdo das anotações é protegido com criptografia **AES-256** no banco de dados.
- **Segurança de Credenciais:** Senhas de usuários protegidas utilizando **Bcrypt** (password_hash).
- **Sessões Protegidas:** Sistema de login e controle de acesso via sessões PHP.
- **Interface Moderna:** Design limpo, corporativo e responsivo feito com HTML e CSS (Flexbox).
- **Proteção contra SQL Injection:** Uso de PDO com *Prepared Statements* em todas as consultas ao banco.

## 🛠️ Tecnologias Utilizadas

- **Backend:** PHP (PDO)
- **Banco de Dados:** MySQL
- **Frontend:** HTML5, CSS3
